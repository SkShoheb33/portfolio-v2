# Shoheb Shaik — Portfolio

A responsive, single-page portfolio built with semantic HTML, Tailwind CSS (CDN), and vanilla JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For best results, run a simple local server (for example `python -m http.server 8000`) from this directory.

## Deploy
- **Netlify / Vercel static hosting:** deploy the folder as a static site.
- **GitHub Pages:** push the folder contents to a repository and enable Pages.

## Included
- `index.html` — site and animations
- `assets/shoheb-portrait.png` — professional portrait
- `assets/shoheb-casual.png` — secondary portrait
- `assets/Shoheb-Shaik-Resume.pdf` — supplied résumé

Tailwind and Google Fonts are loaded from CDNs, so those features require an internet connection. Update contact details, project links, and resume as needed before publishing.
